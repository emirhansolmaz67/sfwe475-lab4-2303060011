# Task Board

A small React and TypeScript task board built for the core activities in SFWE475 / CPRG201 Lab 4.

## Run locally

```sh
npm install
npm run dev
```

## Verify

```sh
npm run lint
npm run build
```

The core implementation covers typed task data, reusable task cards, keyed task lists, a controlled add-task input, and task state owned by `TaskBoard`. The optional filter bar, lifted checkbox updates, and local storage persistence are not included.
